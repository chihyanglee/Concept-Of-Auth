How OAuth 2.0 Works Here

  1. You click "Login" and authenticate with the Auth Server (port 5000)
  2. Auth Server issues an authorization code
  3. This app exchanges the code for access + refresh + ID tokens
  4. Access token is used to call the Task API (port 5002)
  5. ID token tells this app who you are (OpenID Connect)
